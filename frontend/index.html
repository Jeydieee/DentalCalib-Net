DentalCalib-Net Pipeline

Architecture and mechanism of the quality-aware recalibration method.

A — End-to-end inference pipeline

Selected detector
YOLOv8 / RT-DETR
Detection outputs
raw confidence · boxes · logits
Quality feature extraction
per image
Quality features

DentalCalib-Net
3-layer MLP · 8-dim input
Calibrated confidence

B — Temperature scaling vs. DentalCalib-Net
Temperature scaling

Fixed scalar T applied uniformly to all inputs. No sensitivity to image or OOD severity.

DentalCalib-Net

Quality-conditioned correction, designed to apply larger adjustments to degraded images and smaller ones to clean images.

C — 8-dimensional input vector
Detection features (5)
Raw confidence BBox width BBox height BBox center x BBox center y
Image quality features (3): the quality-conditioning mechanism, absent from Temperature Scaling
Laplacian variance (sharpness) Pixel σ (exposure / contrast) JPEG block score (compression)
Safety invariant: DentalCalib-Net modifies confidence scores only. Bounding-box coordinates are unchanged. Because its correction need not be monotonic in the raw score, detections can be re-ranked, so mAP@0.50 can shift and is monitored across all conditions. Temperature Scaling is monotonic, so it leaves the ranking, and therefore mAP@0.50, unchanged.
