B — Temperature scaling vs. DentalCalib-Net
Temperature scaling

Fixed scalar T applied uniformly to all inputs. No sensitivity to image or OOD severity.

DentalCalib-Net

Quality-conditioned correction. Larger adjustments for degraded images, smaller for clean ones.

C — 8-dimensional input vector
Raw confidence BBox w BBox h BBox x BBox y Laplacian variance Pixel σ (exposure) JPEG block score
Safety invariant: DentalCalib-Net modifies confidence scores only. Box coordinates and detection decisions are not altered. mAP@0.50 can still shift after recalibration, because DentalCalib-Net re-ranks confidence scores non-monotonically — unlike Temperature Scaling, which is monotonic and leaves mAP@0.50 unchanged.
